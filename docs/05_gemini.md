# 05. Gemini の活用法 〜動画理解・音声合成・自動化〜

Gemini（ジェミニ）は Google の AI です。この環境では **API キーが発行できる**ため、Claude ではできない「自動化」と「動画・音声を直接扱う仕事」を Gemini が担当します。

Gemini には入り口が3つあります。用途で使い分けましょう。

| 入り口 | 場所 | 向いている用途 | 料金 |
|---|---|---|---|
| ① Gemini アプリ | [gemini.google.com](https://gemini.google.com) | チャット相談、動画を見せて相談 | 無料枠あり（有料プランで強化） |
| ② Google AI Studio | [aistudio.google.com](https://aistudio.google.com) | プロンプトの実験、API キー発行 | 無料 |
| ③ Gemini API | 自作スクリプトから呼ぶ | 定型作業の自動化、音声合成、動画解析 | 無料枠＋従量課金 |

---

## 1. Gemini アプリ（チャットで使う）

Claude と同じように、企画・台本・タイトルの相談ができます（頼み方は [07章 プロンプト集](07_prompts.md) が共用できます）。
Claude との違いで覚えておくべき強みは：

- **動画・音声ファイルを直接アップロードして理解させられる**：「この動画の要約と改善点を教えて」「ショートに切り出すならどこ？」が可能。
- **YouTube 動画の URL を渡して内容について質問できる**（対応状況はプランや地域によります）。競合チャンネルの研究に便利。
- Google 検索と連携した最新情報の回答が得意。
- 有料プラン（Google AI Pro / Ultra）では、動画生成 AI「**Veo**」でショート素材になる動画クリップを生成できます（後述）。

> 💡 使い分けの目安：**文章の質・長い台本づくりは Claude、動画を見せたい・最新情報・自動化は Gemini**。両方に同じ質問をして良いほうを採用する「二刀流」も有効です。

## 2. Google AI Studio（無料の実験場 & API キー発行所）

[Google AI Studio](https://aistudio.google.com) は開発者向けの無料ツールですが、開発者でなくても便利です。

- モデルを選んで長いプロンプトを試せる（システム指示も設定可能）
- 動画・音声・画像をアップロードして試せる
- **ここで API キーを発行します**（次のセクション）

### API キーの発行手順

1. [aistudio.google.com](https://aistudio.google.com) に Google アカウントでログイン。
2. 左メニューまたは画面上部の「**Get API key**（API キーを取得）」をクリック。
3. 「**API キーを作成**」→ プロジェクトを選択（なければ新規作成）。
4. 表示された `AIza...` で始まる文字列が API キーです。**この場で安全な場所に控えます**。

### 無料枠と有料の違い

- API には**無料枠**があります（1分あたり・1日あたりのリクエスト数に制限）。個人の動画制作の補助なら、まず無料枠で足ります。
- 上限に当たる（エラー `429` が返る）ようになったら、Google Cloud の請求設定を紐付けて従量課金に切り替えられます。
- 料金は [公式の料金ページ](https://ai.google.dev/gemini-api/docs/pricing) で必ず最新を確認してください。テキスト処理は非常に安価ですが、**動画生成（Veo）は秒単位の課金でケタが違う**ので注意。

### ⚠️ API キーの安全管理（重要）

API キーは「あなたの財布に直結するパスワード」です。

- ✅ 環境変数に設定して使う（→ [scripts/gemini/README.md](../scripts/gemini/README.md)）
- ❌ スクリプトのコードに直接書かない
- ❌ GitHub などの公開リポジトリにコミットしない（**このリポジトリにも書かないこと！**）
- 漏れたかも？と思ったら AI Studio ですぐ削除して再発行

## 3. Gemini API でできること（動画制作向け）

| できること | 使うモデル（例） | 動画制作での用途 |
|---|---|---|
| テキスト生成 | `gemini-2.5-flash` など | タイトル・概要欄・タグの自動生成 |
| **動画理解** | `gemini-2.5-flash` など（動画入力対応） | 動画を渡してチャプター案・ハイライト抽出 |
| **音声合成（TTS）** | `gemini-2.5-flash-tts` | 台本からナレーション音声（.wav）生成 |
| 画像生成 | Imagen 系 | サムネイル用の背景・イメージ画像 |
| **動画生成** | Veo 系 | 実写風・アニメ風の Bロール素材生成 |

このリポジトリの [scripts/gemini/](../scripts/gemini/README.md) に、上の表の主要パターンをすぐ使えるスクリプトとして用意しています。

- `generate_youtube_metadata.py` — 文字起こし → タイトル・概要欄・タグ・チャプター
- `translate_srt.py` — 字幕 .srt の翻訳（タイムコード維持）
- `generate_narration.py` — 台本 → ナレーション .wav（Premiere にそのまま読み込めます）
- `video_to_chapters.py` — 動画ファイル → チャプター案＋ショート切り出し案

> 💡 モデル名は世代交代します（この文書時点の安定版は 2.5 系。より新しい 3 系が使える場合は各スクリプトの `--model` オプションで差し替え可能）。現行モデルの一覧は [公式モデル一覧](https://ai.google.dev/gemini-api/docs/models) を参照。

## 4. ナレーション音声生成（TTS）について

Gemini の音声合成は自然な日本語ナレーションが作れて、**顔出し・声出しなしの動画**（→ [06章 レシピC](06_workflows.md#レシピc顔出し声出しなしの動画を作る)）の主役になります。

- 声の種類（ボイス）を選べます（例：`Kore`、`Puck` など。[公式ドキュメント](https://ai.google.dev/gemini-api/docs/speech-generation) に一覧とサンプルあり）。
- 「落ち着いたトーンで、ゆっくりめに」のような**演出指示を文章で**与えられます。
- 出力は WAV にして Premiere Pro のタイムラインに置くだけ。
- ⚠️ 合成音声を使った動画は、YouTube の視聴者向けに「合成ナレーションであること」を概要欄に書いておくのが誠実です（→ [06章 チェックリスト](06_workflows.md#投稿前チェックリスト)）。

## 5. 動画生成 AI「Veo」について

Veo は Google の動画生成 AI で、テキストや画像から音声付きの短い動画クリップ（数秒〜十数秒）を生成します。実写素材がない「イメージカット」の穴埋めに使えます。

| 使う場所 | 特徴 |
|---|---|
| Gemini アプリ（有料プラン） | いちばん手軽。プロンプトを書くだけ |
| Flow（Google の映像制作ツール） | カットをつないで短編を作る用途向け |
| Gemini API / AI Studio | スクリプトから生成。**秒単位の従量課金** |

- 品質重視の Veo 3.1、速度重視の Fast、低価格の Lite などのグレードがあります。
- ⚠️ **料金に注意**：動画生成はテキスト生成の数百倍のコスト感です（1秒あたり数円〜数十円のオーダー）。まずは Gemini アプリの有料プラン枠か AI Studio で試し、量産が必要になってから API を検討しましょう。最新の価格は [料金ページ](https://ai.google.dev/gemini-api/docs/pricing) で確認。
- 生成した動画には SynthID（電子透かし）が入ります。リアルな人物映像を生成した場合は YouTube の開示ルールに従ってください（→ [08章 FAQ](08_faq-glossary.md)）。

## 6. Claude と Gemini の分担まとめ

| 作業 | 担当 | 理由 |
|---|---|---|
| 企画・構成・台本 | **Claude**（Gemini でも可） | 長文の文章力・対話での練り込み |
| 動画を見せて相談 | **Gemini** | 動画入力対応 |
| タイトル・概要欄・タグ | どちらでも | 両方に出させて良い方を採用もアリ |
| 字幕の校正 | Claude（チャット貼り付け） | 文章の自然さ |
| 字幕の翻訳（大量・定期） | **Gemini API**（スクリプト） | 自動化できる |
| ナレーション音声 | **Gemini API**（TTS） | Claude は音声を作れない |
| Bロール動画生成 | **Gemini（Veo）** または Adobe Firefly | |
| ファイル一括処理 | Claude Code または Gemini API | 好みで |
