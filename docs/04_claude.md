# 04. Claude の活用法 〜企画・台本・文章まわりの相棒〜

Claude（クロード）は Anthropic 社の AI アシスタントです。
この環境では **Claude の API キーは発行できません**が、心配いりません。
動画制作で Claude が活躍するのは「**企画・台本・タイトルなど、人間が考えて書く部分**」であり、これは [claude.ai](https://claude.ai) のチャット画面（Web / スマホアプリ / デスクトップアプリ）で完結します。API キーが必要な自動化は、API キーを発行できる Gemini に任せる分担です（→ [05章](05_gemini.md)）。

---

## 1. Claude が得意な作業マップ

| 制作フェーズ | Claude に頼めること |
|---|---|
| 企画 | ネタ出し、切り口の提案、ターゲット整理、競合との差別化案 |
| 構成 | 動画の構成案（つかみ→本編→まとめ）、尺の配分 |
| 台本 | 話し言葉の台本執筆、リライト、「30秒短くして」等の調整 |
| 撮影・編集 | 撮影カット表の作成、文字起こしからの不要箇所の指摘 |
| 公開準備 | タイトル案、概要欄、タグ、チャプター、サムネイル文言 |
| 字幕 | 文字起こしの誤字修正、.srt の校正・翻訳（貼り付けで） |
| 運用 | コメント返信案、次回動画のネタ分析 |

具体的な頼み方の文例は [07章 プロンプト集](07_prompts.md) にまとめています。

## 2. 基本の使い方と「良い頼み方」

[claude.ai](https://claude.ai) にログインして、チャットに日本語で話しかけるだけです。
ただし、**頼み方で成果物の質が大きく変わります**。次の4点セットを意識してください。

```
① 背景   ：私は◯◯についての YouTube チャンネルを運営しています
② 目的   ：視聴維持率を意識した10分の解説動画を作りたい
③ 条件   ：視聴者は初心者。専門用語は例え話で。一人称は「僕」
④ 形式   ：話し言葉の台本形式で。見出しと目安時間付きで
```

- 出力が気に入らなければ「もっとカジュアルに」「冒頭のつかみを3パターン」など、**会話で修正を重ねる**のが Claude の使い方のコツです。1回で完璧を求めなくて OK。
- 長い台本は「まず構成案 → OK なら各セクションを順に執筆」と**分割して進める**と精度が上がります。

### ファイルを渡せる
チャット欄にファイルを添付できます。動画制作でよく渡すのは：

- **文字起こしの .txt**（Premiere Pro から書き出したもの → [02章](02_premiere-ai-features.md#1-自動文字起こしすべての土台)）→ タイトル・概要欄・チャプター生成の元ネタに
- **字幕の .srt** → 誤字チェックや翻訳に
- 台本の下書き、参考資料の PDF など

> ⚠️ **動画ファイルや音声ファイルそのものは Claude では扱えません。**「動画の内容を見て◯◯して」という仕事は、①Premiere の文字起こしを渡す、または ②動画を直接理解できる Gemini を使う（→ [05章](05_gemini.md)）、のどちらかで解決します。

## 3. プロジェクト機能でチャンネル情報を記憶させる

毎回「私のチャンネルは〜」と説明するのは面倒です。claude.ai の **プロジェクト（Projects）機能**を使うと、前提情報を保存して使い回せます。

### 設定手順
1. claude.ai の左サイドバーから「**プロジェクト**」→「新規プロジェクト」を作成（例：`YouTubeチャンネル運営`）。
2. プロジェクトの「**指示（Instructions）**」に、チャンネルの前提を書いておく：

```
このプロジェクトでは、私の YouTube チャンネルの制作を手伝ってください。

- チャンネル名：【チャンネル名】
- ジャンル：【例：ガジェット紹介／料理／プログラミング解説】
- 視聴者層：【例：20〜30代の初心者】
- 動画の長さ：通常8〜12分、ショートは60秒
- トーン：【例：丁寧だけど堅すぎない。一人称は「私」】
- タイトルの好み：【例：数字を入れる。煽りすぎない】
- 禁止事項：【例：誇大表現、他者への攻撃的な表現】
```

3. 過去の台本や再生数が良かった動画のタイトル一覧などを**プロジェクトナレッジ**としてアップロードしておくと、文体やヒットパターンを踏まえた提案をしてくれます。
4. 以後、このプロジェクト内でチャットを始めるだけで、前提を踏まえた回答になります。

## 4. （中級）Claude Code でファイル作業を自動化する

**Claude Code** は、Claude にパソコン上のファイル操作やコマンド実行を任せられるツールです。**API キー不要で、claude.ai のサブスクリプションアカウントでログインして使えます**（対応プランは [公式ドキュメント](https://code.claude.com/docs) を確認してください）。

動画制作での使いどころの例：

- 「`subtitles/` フォルダーの .srt 全部の誤字を直して、`fixed/` に保存して」
- 「撮影素材のファイル名を `日付_連番_内容.mp4` の形式に一括リネームして」
- 「今月の動画の概要欄テキストをテンプレートから10本分生成して」

つまり、**チャット1往復では終わらない「手元のファイルをまとめて処理する仕事」**を日本語で頼めます。ターミナル（黒い画面）に抵抗がなければ強力な選択肢です。無理に使う必要はありません — まずは claude.ai のチャットだけで十分です。

## 5. Claude の制限と注意点

| 項目 | 内容 |
|---|---|
| 動画・音声の直接理解 | ❌ 不可。Premiere の文字起こし .txt を経由するか、Gemini を使う |
| API キー | ❌ 発行不可（この環境の契約）。自動処理パイプラインは Gemini API で組む |
| 利用回数 | プランに応じて一定時間あたりの利用量に上限あり。長い台本作業は余裕のある時間帯に |
| 最新情報 | Web 検索機能が有効なら調べながら回答可能。ただし**事実（数値・日付・仕様）は必ず自分でも裏取り**する |
| 機密情報 | ⚠️ 勤務先の非公開情報や個人情報を貼らない。動画で公開する予定の内容に留める |
| 著作権 | Claude が書いた台本でも、**内容の正確性と権利の最終責任は投稿者**にあります。引用・出典の確認は人間の仕事 |
