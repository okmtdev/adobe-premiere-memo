# 06. 実践レシピ 〜企画から投稿まで、AI と一緒に1本作る〜

この章では、これまでの道具（Premiere Pro の AI 機能・Adobe Stock・Claude・Gemini）を全部つないで、**実際に動画が1本できるまでの流れ**を3パターン紹介します。

- [レシピA：しゃべり系の解説動画を作る](#レシピaしゃべり系の解説動画を作る)（王道。まずはこれ）
- [レシピB：本編からショート動画を作る](#レシピb本編からショート動画を作る)
- [レシピC：顔出し・声出しなしの動画を作る](#レシピc顔出し声出しなしの動画を作る)

---

## 全体像

どのレシピも、大きな流れは同じです。

```
企画 ──▶ 台本 ──▶ 素材集め・撮影 ──▶ 編集 ──▶ 公開準備 ──▶ 投稿
 └ Claude   └ Claude    └ Adobe Stock     └ Premiere    └ Claude/Gemini
                          (+Veo/Firefly)     の AI 機能
```

**「考える・書く」は Claude、「編集作業」は Premiere の AI、「音声合成・自動化・動画理解」は Gemini** という分担です。

## レシピA：しゃべり系の解説動画を作る

カメラ（スマホで OK）に向かって話す、8〜12分の解説動画を想定します。

### A-1. 企画を立てる（Claude / 15分）

1. claude.ai を開く（プロジェクト機能を設定済みなら、そのプロジェクト内で → [04章](04_claude.md#3-プロジェクト機能でチャンネル情報を記憶させる)）。
2. [07章のプロンプト1「企画・ネタ出し」](07_prompts.md#1-企画ネタ出し) を貼り付け、テーマを埋めて送信。
3. 出てきた案から1つ選び、「この案で、視聴者が最後まで見たくなる構成案を作って」と続ける。

### A-2. 台本を書く（Claude / 30分）

1. 構成案に OK を出したら、[プロンプト3「台本執筆」](07_prompts.md#3-台本執筆) で台本化。
2. 声に出して読んでみて、言いにくい箇所を「もっと話し言葉に」「ここに例え話を足して」と修正依頼。
3. 完成した台本はテキストファイルで保存（あとで概要欄づくりにも使います）。

> 💡 台本の事実関係（数値・仕様・日付）は必ず自分で確認しましょう。AI は自信満々に間違えることがあります。

### A-3. 撮影する（30分〜）

- スマホでも十分です。窓に向かって座る（顔が明るくなる）、できれば口とマイクの距離を近く。
- 言い間違えても止めずに、**同じ文を言い直してそのまま続けて OK**。あとで AI カットするので気楽に。

### A-4. 編集する（Premiere Pro / 1〜2時間）

[02章](02_premiere-ai-features.md) の「黄金パターン」の通りに進めます。

1. **読み込み**：自動文字起こしをオンにして素材を読み込む。
2. **粗カット**：テキストパネルの文字起こしで、言い直し・脱線を選択して削除（**テキストベース編集**）。「一時停止を削除」で間もカット。
3. **声の補正**：しゃべりクリップに **スピーチを強調**。
4. **BGM**：Adobe Stock か YouTube オーディオライブラリから BGM を配置（→ [03章](03_adobe-stock.md)）→ **リミックス**で長さを合わせ、**オートダッキング**でしゃべり中の音量を自動調整。
5. **挿絵・Bロール**：説明が単調な部分に Adobe Stock の画像・動画を V2 トラックに載せる。素材探しの検索語は Claude に出してもらう（[プロンプト10「Adobe Stock 検索キーワード」](07_prompts.md#10-adobe-stock-検索キーワード)）。
6. **字幕**：文字起こしから**キャプションを自動生成** → トラックスタイルで見た目を統一。
7. **色**：Lumetri カラーの「自動」ボタン → 気になれば微調整。
8. **見直し**：通しで再生して違和感を潰す。

### A-5. 公開の材料を作る（Claude or Gemini / 15分）

1. Premiere のテキストパネルから**文字起こしを .txt で書き出す**。
2. 方法はどちらでも：
   - **チャット派**：claude.ai に .txt を添付して [プロンプト5「タイトル・概要欄・タグの一括生成」](07_prompts.md#5-タイトル概要欄タグの一括生成) を実行。
   - **自動化派**：`python scripts/gemini/generate_youtube_metadata.py 文字起こし.txt` を実行（→ [scripts/gemini/README.md](../scripts/gemini/README.md)）。
3. タイトルは候補から選び、**自分の言葉で最終調整**（AI っぽい誇張は削る）。

### A-6. サムネイルを作る

[下のサムネイル節](#サムネイルを作る) を参照。

### A-7. 書き出して投稿する

1. 書き出しタブ → YouTube 1080p プリセットで .mp4 に（→ [01章 Step10](01_premiere-basics.md#step-10-書き出す)）。
2. YouTube Studio でアップロードし、タイトル・概要欄・タグ・サムネイル・チャプターを設定。
3. [投稿前チェックリスト](#投稿前チェックリスト) で最終確認 → 公開！

## レシピB：本編からショート動画を作る

レシピAで作った横動画から、60秒の縦ショートを切り出します。**1本の本編から2〜3本のショートを作る**のが定番の運用です。

### B-1. 切り出し箇所を決める（Gemini / 10分）

方法はどちらでも：

- **アプリ派**：Gemini アプリに完成動画（または YouTube にアップ済みなら URL）を渡して、「この動画からショートに切り出すのに最適な60秒以内の箇所を3つ、開始・終了タイムコードと理由付きで提案して」。
- **スクリプト派**：`python scripts/gemini/video_to_chapters.py 完成動画.mp4` — チャプター案と一緒にショート切り出し案も出力します。

### B-2. Premiere で切り出す（15分）

1. 本編のシーケンスを複製（プロジェクトパネルで右クリック → 複製）。名前を `◯◯_short1` などに。
2. 提案されたタイムコードの範囲だけ残して、前後を削除。
3. 60秒に収まるよう、テキストベース編集でさらに間を詰める。

### B-3. 縦にする（5分）

1. シーケンスを右クリック →「**オートリフレームシーケンス**」→ 9:16（→ [02章](02_premiere-ai-features.md#8-オートリフレーム横動画を縦動画に自動変換)）。
2. 被写体の追従を確認、ズレたクリップだけ手動修正。

### B-4. ショート向けの仕上げ（15分）

- 字幕を**大きく**（画面中央〜下 1/3、1行あたりの文字数少なめに再生成すると読みやすい）。
- 冒頭1秒に結論やフック（「◯◯、実は損してます」等）のテロップ。フックの文言は Claude に相談（[プロンプト13「ショートのフック・タイトル」](07_prompts.md#13-ショートのフックタイトル)）。
- 書き出しは 1080×1920。タイトルに `#Shorts` を入れるか、3分以内の縦動画として投稿。

## レシピC：顔出し・声出しなしの動画を作る

自分は映らず、**AI ナレーション＋素材映像**で作る形式です。解説系・ランキング系・雑学系チャンネルの定番です。

### C-1. 台本を書く（Claude）

- レシピA-1〜A-2 と同じ。ただし「ナレーション向けに、聞いてわかりやすい文章で。1文は短めに」と条件を足す。

### C-2. ナレーション音声を生成する（Gemini API / 10分）

1. 台本を `script.txt` として保存（読み上げ用に、見出しなどの「読まない文字」は削っておく）。
2. 実行：

```bash
python scripts/gemini/generate_narration.py script.txt --voice Kore --style "落ち着いた解説調で、ややゆっくり"
```

3. できた `.wav` を Premiere Pro に読み込み、A1 トラックに配置。
   - 聞いてみて発音がおかしい単語は、台本側をひらがなに直して再生成（例：「重複」→「ちょうふく」）。

### C-3. 映像を組み立てる（Premiere Pro）

1. ナレーションに合わせて、**Adobe Stock のビデオ素材**を並べていく（→ [03章](03_adobe-stock.md)）。
2. 素材が見つからないイメージカットは：
   - **Firefly** で画像生成して、ゆっくりズームさせる（画像に「スケール」のキーフレーム）。
   - または **Veo** で動画クリップを生成（→ [05章](05_gemini.md#5-動画生成-aiveoについて)）。
3. カットの尻が足りないときは**生成拡張**で延長（→ [02章](02_premiere-ai-features.md#9-生成拡張クリップの足りない尻尾を-ai-が生成)）。
4. 素材の色味がバラバラなら **カラーマッチ** で統一。

### C-4. 字幕と仕上げ

1. ナレーション音声にも**自動文字起こし → キャプション生成**が使えます（レシピAと同じ）。
2. BGM＋オートダッキング、書き出しもレシピAと同じ。
3. ⚠️ 概要欄に「ナレーションは AI 音声合成を使用しています」と一言入れておくのがおすすめです。

## サムネイルを作る

Photoshop がなくても大丈夫です。

1. **文言を決める**：Claude に [プロンプト7「サムネイル文言」](07_prompts.md#7-サムネイル文言) で「13文字以内のパワーワード」を出してもらう。
2. **背景・ベース画像**：
   - 動画のいいシーンを Premiere Pro で書き出す：プログラムモニター下の**カメラアイコン（フレームを書き出し）**で静止画保存。
   - 足りなければ Adobe Stock 検索 or **Firefly** で生成（→ [03章](03_adobe-stock.md#5-ai-生成素材と-firefly)）。
3. **文字入れ**：[Adobe Express](https://www.adobe.com/jp/express/)（ブラウザで動く簡易デザインツール。YouTube サムネイル用テンプレートあり）で、画像＋大きな文字＋縁取りを組み合わせる。
4. 1280×720（16:9）で書き出し。**スマホの小さい画面で読めるか**を必ず確認。

## 投稿前チェックリスト

コピーして使ってください。

```
□ 通しで最後まで再生して確認した（音量・誤字・消し忘れ素材）
□ 冒頭 15 秒に「この動画で何がわかるか」が入っている
□ タイトル：候補から選んで自分の言葉で調整した（60文字以内目安）
□ 概要欄：要約・チャプター・関連リンク・SNS を記載
□ タグを設定した
□ サムネイル：スマホサイズで文字が読める
□ 字幕（.srt または焼き込み）を付けた
□ 終了画面・カードを設定した（次の動画へ誘導）
□ BGM・素材のライセンスに問題がない（→ 03章）
□ AI 生成コンテンツの扱いを確認した：
   - リアルに見える生成映像・実在人物風の合成を使った場合、
     YouTube Studio の「変更されたコンテンツ」開示にチェック
   - AI ナレーション使用なら概要欄に明記（推奨）
□ 公開設定（公開 / 限定公開 / スケジュール）を確認した
```

> 📈 投稿後1週間くらいしたら、YouTube Studio のアナリティクス（視聴維持率グラフ）のスクリーンショットを Claude / Gemini に見せて「どこで離脱されてる？次回どう改善する？」と相談すると、次の動画がどんどん良くなります。
