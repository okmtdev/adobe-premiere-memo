# 01. Premiere Pro 超入門 〜はじめての1本を作る〜

この章では、AI 機能を使う前に知っておきたい「Premiere Pro の基本」だけを説明します。
覚えることは最小限に絞っています。**完璧に理解しなくて大丈夫**です。あとで何度でも戻ってきてください。

> 💡 メニューやボタンの名前は Premiere Pro のバージョンによって少し違うことがあります。見つからないときは、画面上部の「ヘルプ」メニューから検索するか、[Adobe 公式ヘルプ](https://helpx.adobe.com/jp/premiere-pro/user-guide.html) を確認してください。

---

## 1. 最初に覚える用語は7つだけ

| 用語 | 意味 | イメージ |
|---|---|---|
| **プロジェクト** | 動画1本分の作業ファイル（.prproj） | 「工作の作業机」 |
| **クリップ** | 読み込んだ動画・音声・画像の1つ1つ | 「材料」 |
| **シーケンス** | クリップを並べて1本の動画にする場所 | 「設計図兼、組み立て台」 |
| **タイムライン** | シーケンスを時間軸で表示している画面下部のパネル | 「組み立て台を上から見た図」 |
| **カット編集** | いらない部分を切って捨てる作業 | 動画編集の8割はこれ |
| **テロップ / 字幕** | 画面に載せる文字 | 「キャプション」とも呼ぶ |
| **書き出し** | 完成した動画を1本の動画ファイル（.mp4 など）にすること | 「完成品の梱包」 |

---

## 2. 画面の見方（編集ワークスペース）

Premiere Pro を起動してプロジェクトを開くと、画面上部に「**読み込み**」「**編集**」「**書き出し**」のタブがあります。作業は基本的にこの順で進みます。

「編集」タブの画面は、ざっくり4つのエリアでできています。

```
┌─────────────────┬─────────────────┐
│ ① ソースモニター        │ ② プログラムモニター     │
│ （素材の下見をする画面）  │ （完成形を確認する画面）  │
├─────────────────┼─────────────────┤
│ ③ プロジェクトパネル     │ ④ タイムライン          │
│ （読み込んだ素材の棚）    │ （クリップを並べる場所）  │
└─────────────────┴─────────────────┘
```

- 迷子になったら：メニューの **「ウィンドウ」→「ワークスペース」→「保存されたレイアウトにリセット」** で初期配置に戻せます。
- パネルが見つからないときは：**「ウィンドウ」メニュー** に全パネルの一覧があります（後の章で使う「テキスト」「エッセンシャルサウンド」もここにあります）。

## 3. はじめての1本：10ステップ

スマホで撮った動画などを1本の YouTube 動画にする、最短の流れです。

### Step 1. 新規プロジェクトを作る
1. Premiere Pro を起動 →「**新規プロジェクト**」をクリック。
2. プロジェクト名（例：`2026-07-12_はじめての動画`）と保存場所を決めます。
   - 💡 動画素材と同じフォルダーにまとめておくと、あとで迷子になりません。

### Step 2. 素材を読み込む
1. 画面上部の「**読み込み**」タブで、動画ファイルのあるフォルダーを開き、使う素材にチェックを入れます。
2. 右下の「**作成**」を押すと、素材が読み込まれてシーケンスも自動で作られます。
   - 💡 このとき読み込み設定に「**自動文字起こし**」のスイッチがあればオンにしておくと、後の字幕作成（→ [02章](02_premiere-ai-features.md)）が楽になります。

### Step 3. 再生して全体を把握する
- **Space キー**で再生／停止。タイムライン上の青い縦線（**再生ヘッド**）が今見ている位置です。
- **J / K / L キー** で 巻き戻し / 停止 / 早送り ができます（L を2回押すと2倍速）。

### Step 4. いらない部分をカットする
1. ツールバーの **レーザーツール（C キー）** を選び、切りたい位置でクリップをクリックすると分割されます。
2. **選択ツール（V キー）** に戻して、いらない部分をクリック → **Shift + Delete**（Mac は Shift + fn + Delete）で「**リップル削除**」。
   - リップル削除＝削除した隙間を自動で詰めてくれる削除。基本はこちらを使います。
   - 💡 「えー」「あー」などの言い直しカットは、AI の**テキストベース編集**（→ [02章](02_premiere-ai-features.md#3-テキストベース編集文字を消すと動画も切れる)）を使うと劇的に楽です。

### Step 5. クリップを並べ替える
- タイムライン上でクリップをドラッグして順番を入れ替えられます。
- 上のトラック（V2, V3…）に置いたものほど手前に表示されます（画像を重ねるときに使います）。

### Step 6. テロップ（文字）を入れる
1. ツールバーの **文字ツール（T キー）** を選び、プログラムモニター上でクリックして文字を入力。
2. 「**エッセンシャルグラフィックス**」パネル（ウィンドウ → エッセンシャルグラフィックス）でフォント・サイズ・色・縁取りを調整。
   - 💡 しゃべりに合わせた字幕を全部手で打つ必要はありません。**自動文字起こし → キャプション生成**（→ [02章](02_premiere-ai-features.md)）を使いましょう。

### Step 7. BGM を入れる
1. BGM の音声ファイルをプロジェクトパネルへドラッグして読み込み。
2. タイムラインの **A2 トラック**（しゃべり声が A1 にある場合）へドラッグして配置。
3. 音量調整はクリップ上の白い横線（ラバーバンド）を上下にドラッグ。
   - 💡 「しゃべっている間だけ BGM を自動で小さく」は AI の**オートダッキング**（→ [02章](02_premiere-ai-features.md#7-オートダッキングしゃべり中だけbgmを自動で下げる)）で一発です。
   - 🎵 BGM 素材の入手は [03章 Adobe Stock](03_adobe-stock.md) を参照。

### Step 8. 音量の目安を確認する
- 画面右側の**オーディオメーター**を見ながら再生し、しゃべり声がおおむね **-6dB 前後**、ピークが 0dB を超えて赤くならないように調整します。
- 声が聞き取りにくいときは **スピーチを強調**（→ [02章](02_premiere-ai-features.md#5-スピーチを強調ノイズを消して声をクリアに)）。

### Step 9. 色を軽く整える（任意）
- 「**Lumetri カラー**」パネル（ウィンドウ → Lumetri カラー）の「基本補正」にある「**自動**」ボタンを押すだけでも見栄えが変わります。

### Step 10. 書き出す
1. 画面上部の「**書き出し**」タブへ。
2. プリセットから「**ソースの一致 - 高速ビットレート**」または「**YouTube 1080p フル HD**」を選択。
3. ファイル名と保存場所を確認して「**書き出し**」をクリック。
   - 形式は **H.264（.mp4）** になっていれば OK。これが YouTube の定番です。
   - 💡 書き出しタブから YouTube アカウントに直接ログインしてアップロードもできますが、最初はファイルに書き出してから YouTube Studio で手動アップロードするほうが、サムネイルや公開設定を落ち着いて確認できるのでおすすめです。

## 4. YouTube 向け設定の早見表

| 項目 | 通常動画（横） | ショート（縦） |
|---|---|---|
| 解像度 | 1920×1080（フル HD）| 1080×1920 |
| アスペクト比 | 16:9 | 9:16 |
| 形式 | H.264 / .mp4 | H.264 / .mp4 |
| フレームレート | 撮影素材に合わせる（30fps か 60fps が多い） | 同左 |
| 長さ | 自由 | 3分以内（60秒以内が主流） |

- シーケンス設定は「素材のクリップをタイムラインにドラッグして自動作成」されたものを使えば、基本的に触らなくて大丈夫です。
- 横動画から縦のショートを作るときは **オートリフレーム**（→ [02章](02_premiere-ai-features.md#8-オートリフレーム横動画を縦動画に自動変換)）を使います。

## 5. 保存とトラブル対策

- 保存は **Ctrl + S**（Mac: Cmd + S）。こまめに押す癖をつけましょう。
- Premiere Pro には**自動保存**もあります（環境設定 → 自動保存）。デフォルトで有効です。
- 動作が重い・プレビューがカクつくときは：
  - プログラムモニター右下の再生解像度を「**1/2**」や「**1/4**」に下げる。
  - それでも重い素材は、タイムラインで範囲を選んで **Enter キー**（レンダリング）を押しておくと滑らかに再生できます。

## 6. 最初に覚えるショートカット

| キー | 動作 |
|---|---|
| Space | 再生 / 停止 |
| J / K / L | 戻る / 停止 / 進む |
| C | レーザーツール（切る） |
| V | 選択ツール |
| T | 文字ツール |
| Shift + Delete | リップル削除（隙間を詰めて削除） |
| Ctrl(Cmd) + Z | 取り消し |
| Ctrl(Cmd) + S | 保存 |
| ± / − | タイムラインの拡大・縮小 |
