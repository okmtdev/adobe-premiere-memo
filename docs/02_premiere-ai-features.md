# 02. Premiere Pro の AI 機能マニュアル

Premiere Pro には AI（Adobe Sensei / Firefly）を使った機能が標準搭載されています。
**追加料金なしで使えるものがほとんど**で、YouTube 動画作りの面倒な作業を大幅に減らせます。

この章では「YouTube 動画作りでよく使う順」に説明します。

> 💡 メニュー名・画面はバージョンによって多少異なります（本章は 2025〜2026 年リリースの Premiere Pro を想定）。最新情報は [Premiere Pro の新機能（公式）](https://helpx.adobe.com/jp/premiere-pro/using/whats-new.html) を確認してください。

## AI 機能の全体マップ

| 機能 | 何が楽になるか | 場所 |
|---|---|---|
| ① 自動文字起こし | しゃべりを全文テキスト化 | テキストパネル |
| ② 自動キャプション | 字幕を自動生成 | テキストパネル |
| ③ テキストベース編集 | 文字を消すと動画もカットされる | テキストパネル |
| ④ キャプションの翻訳 | 字幕を多言語化（27言語対応） | テキストパネル |
| ⑤ スピーチを強調 | 声のノイズ除去・明瞭化 | エッセンシャルサウンド |
| ⑥ リミックス | BGM の長さを自動調整 | エッセンシャルサウンド |
| ⑦ オートダッキング | しゃべり中だけ BGM を自動で下げる | エッセンシャルサウンド |
| ⑧ オートリフレーム | 横動画→縦動画の自動変換 | シーケンスメニュー |
| ⑨ 生成拡張 | クリップの尻尾を AI が生成して延長 | ツールバー |
| ⑩ メディアインテリジェンス検索 | 「夕焼けのシーン」等の言葉で素材検索 | 検索パネル |
| ⑪ オブジェクトマスク | 人や物を自動で選択・追跡 | プログラムモニター／エフェクト |
| ⑫ その他（モーフカット等） | ジャンプカットを滑らかに 等 | エフェクト |

## 1. 自動文字起こし（すべての土台）

**しゃべっている内容を AI が全文テキスト化**します。字幕・テキストベース編集・（後述の）Claude / Gemini 連携すべての起点になる、一番大事な機能です。日本語対応、追加料金なし、処理はローカル（パソコン内）で行われます。

### 使い方
1. メニューの **「ウィンドウ」→「テキスト」** でテキストパネルを開く。
2. 「**文字起こし**」タブ →「**シーケンスを文字起こし**」ボタンをクリック。
3. 言語が「**日本語**」になっていることを確認して開始。
   - 話者が複数いる場合は「話者のラベル付け」をオンにすると、話者ごとに区別されます。
4. 数分待つと、タイムラインと連動した文字起こしが表示されます。テキストをクリックするとその場面にジャンプできます。

### コツ・注意
- 💡 素材の**読み込み時**に自動文字起こしをオンにしておくと（環境設定 → 文字起こし）、クリップを置いた時点で文字起こし済みになります。
- 固有名詞や専門用語は誤変換されがちです。文字起こしテキスト上でダブルクリックすれば直接修正できます。
- 全文テキストは書き出せます：文字起こしパネル右上の「…」→「**書き出し**」→ プレーンテキスト（.txt）。**この .txt を Claude / Gemini に渡すのが AI 活用の基本パターンです**（→ [04章](04_claude.md)・[05章](05_gemini.md)）。

## 2. 自動キャプション（字幕を一瞬で）

文字起こしから、**タイミングの合った字幕（キャプション）を自動生成**します。字幕を1枚ずつ手で作る必要はもうありません。

### 使い方
1. 文字起こしが済んだ状態で、テキストパネルの「**キャプション**」タブへ。
2. 「**文字起こしからキャプションを作成**」をクリック。
3. 1行の最大文字数・行数などを聞かれるので、最初はそのまま「作成」で OK。
4. タイムラインの一番上に **字幕専用トラック** ができ、字幕が並びます。

### 見た目を整える
1. 字幕クリップをどれか1つ選択 → 「**エッセンシャルグラフィックス**」パネルでフォント・サイズ・色・背景・縁取りを調整。
2. 「**トラックスタイル**」として保存しておくと、**全字幕に一括適用**され、次回の動画でも使い回せます。
   - 💡 YouTube では「白文字＋黒縁取り＋画面下部」が定番で読みやすいです。ショートでは大きめに。

### 字幕ファイルとして書き出す
- キャプションは **.srt ファイル**として書き出せます（キャプションタブの「…」→ 書き出し）。
- YouTube Studio に .srt をアップロードすれば「焼き込みでない字幕」（視聴者がオンオフできる字幕）にもなります。
- **.srt を Gemini API で翻訳**するスクリプトを用意しています → [scripts/gemini/translate_srt.py](../scripts/gemini/README.md)。

---

## 3. テキストベース編集（文字を消すと動画も切れる）

文字起こしされた文章を **ワープロのように編集すると、動画のほうが連動してカットされる**機能です。「えー」「あー」、言い直し、沈黙のカットが劇的に速くなります。**しゃべり系動画の編集ではこれが主役です。**

### 使い方
1. テキストパネルの「**文字起こし**」タブを開く。
2. いらない発言をドラッグして選択 → **Delete キー**（またはリップル削除ボタン）。→ タイムラインの該当部分もカットされます。
3. 「**一時停止を削除**」機能を使うと、無言の「間」をまとめて検出して一括削除できます（文字起こしパネルの「…」メニューやフィルターアイコンから）。

### コツ・注意
- まずテキストベース編集で「話の内容」を整えてから、タイムラインで細かい調整をする、という2段構えが効率的です。
- カットしすぎると呼吸感がなくなり不自然になります。プレビューで確認しながら進めましょう。
- 💡 文字起こし全文を Claude に貼って「**カットすべき冗長な箇所を指摘して**」と頼むと、構成レベルの取捨選択の相談もできます（→ [07章 プロンプト集](07_prompts.md)）。

## 4. キャプションの翻訳（多言語字幕）

作成したキャプションを、**AI が多言語（27言語対応）に翻訳**します。英語字幕を付けると海外からの視聴も見込めます。

### 使い方
1. キャプション作成済みの状態で、テキストパネル「キャプション」タブの「**…**」メニュー →「**キャプションを翻訳**」。
2. 翻訳先の言語（例：英語）を選ぶと、**翻訳された字幕トラックが別トラックとして追加**されます。
3. 書き出したい言語のトラックだけ有効にして書き出すか、.srt として書き出して YouTube にアップロードします。

### コツ
- 機械翻訳なので、タイトルに関わる重要なフレーズだけでも見直すと品質が上がります。
- より文脈を汲んだ翻訳にしたい場合は、.srt を書き出して Claude に「意訳込みで自然な英語に」と頼む方法もあります（→ [07章](07_prompts.md)）。大量処理は Gemini API スクリプトが便利です。

---

## 5. スピーチを強調（ノイズを消して声をクリアに）

エアコンの音・反響・環境ノイズを AI が除去し、**スタジオ収録のような声質に補正**します。マイクなしでスマホ収録した音声でも聞きやすくなります。

### 使い方
1. タイムラインで**しゃべり声のクリップ**を選択。
2. **「ウィンドウ」→「エッセンシャルサウンド」** でパネルを開き、オーディオタイプから「**会話**」を選択。
3. 「**修復**」の中の「**スピーチを強調**」にチェックを入れる。
4. 適用量（ミックス量）のスライダーで、効き具合を調整。

### コツ・注意
- **効かせすぎると声が加工っぽくなります**。50〜70% くらいから試すのがおすすめ。
- BGM や効果音のクリップには使わないでください（「会話」専用です）。
- 処理に少し時間がかかります（クラウド処理のためネット接続が必要な場合があります）。

## 6. リミックス（BGM の長さを動画にぴったり合わせる）

「BGM が動画より30秒長い…」というとき、**曲の構成を AI が解析して、自然につなぎ直して指定の長さに変えて**くれます。フェードアウトで誤魔化す必要がありません。

### 使い方
1. タイムラインの BGM クリップを選択。
2. エッセンシャルサウンドパネルでオーディオタイプ「**ミュージック**」を選択。
3. 「**デュレーション**」→ 方式を「**リミックス**」にして、目標の長さを入力。
4. クリップに波線の切れ目マークが付き、自然な位置で曲が編集されます。

---

## 7. オートダッキング（しゃべり中だけBGMを自動で下げる）

しゃべりが始まると BGM の音量が**自動でスッと下がり、しゃべり終わると戻る**、プロっぽい音量調整を自動化します。

### 使い方
1. **しゃべりのクリップ**にエッセンシャルサウンドで「会話」タグを付ける（前述）。
2. **BGM のクリップ**を選択し、「ミュージック」タグを付ける。
3. 「**ダッキング**」にチェック → ダッキングターゲットが「会話」になっていることを確認 →「**キーフレームを生成**」をクリック。
4. BGM クリップに音量のキーフレーム（自動の上げ下げ）が打たれます。

### コツ
- 下げ幅（ダッキング適用量）はデフォルトでだいたい良い感じですが、BGM がうるさいと感じたら -20dB 前後まで下げてみてください。
- しゃべりをカット編集し直したら、もう一度「キーフレームを生成」を押して作り直しましょう。

---

## 8. オートリフレーム（横動画を縦動画に自動変換）

16:9 の横動画を 9:16 の縦（ショート用）などに変換するとき、**被写体を AI が追いかけて、常にフレームの中心に収まるように自動でパン**してくれます。

### 使い方（シーケンスごと変換）
1. 完成した横動画のシーケンスをプロジェクトパネルで右クリック →「**オートリフレームシーケンス**」。
2. アスペクト比で「**縦方向 9:16**」を選択 →「作成」。
3. 縦版のシーケンスが複製されて生成されます。被写体の追従具合を確認し、ズレているクリップだけ位置を手動調整します。

### コツ
- モーショントラッキングは「スピード優先／デフォルト／滑らかな動き優先」が選べます。人がよく動く素材は「スピード優先」。
- 字幕・テロップは縦用に作り直すときれいです（横動画の字幕は縦だと小さすぎることが多い）。
- ショート作りの全体の流れは [06章 レシピB](06_workflows.md#レシピb本編からショート動画を作る) を参照。

## 9. 生成拡張（クリップの足りない尻尾を AI が生成）

「あと1秒素材が長ければ、いいところでカットできるのに…」というとき、**Adobe Firefly の生成 AI が映像・音声の続きを生成してクリップを延長**します。

- 映像：最大 **2秒** 延長（4K・縦動画対応）
- 音声（環境音など）：最大 **10秒** 延長

### 使い方
1. ツールバーから「**生成拡張ツール**」を選択（矢印アイコン長押しのグループ内にあります）。
2. タイムラインで、延ばしたいクリップの**端をつかんで外側にドラッグ**。
3. 数十秒待つと、生成されたフレームで隙間が埋まります。生成部分にはマークが付きます。

### コツ・注意
- カットの「余韻」を作る、トランジションの糊しろを作る、といった**短い延長**に向いています。長く延ばすほど不自然になりやすいです。
- インターネット接続が必要です（クラウドで生成）。
- **生成クレジット**（Adobe の生成 AI 利用枠）を消費する場合があります。プランごとの付与数と消費条件は [生成拡張の FAQ（公式）](https://helpx.adobe.com/jp/premiere-pro/using/generative-extend-faq.html) と自分の [Adobe アカウントページ](https://account.adobe.com/) で確認してください。
- 生成された部分には**コンテンツクレデンシャル**（AI 生成であることの来歴情報）が付与されます。

## 10. メディアインテリジェンス検索（言葉で素材を探す）

「**夕焼けのビーチ**」「**犬がジャンプするカット**」のように、**普通の言葉で映像素材を検索**できます。AI が映像の内容・文字起こし・メタデータを解析して探してくれるので、大量の素材から目当てのカットを見つけるのが一瞬になります。処理はローカルで行われ、素材が勝手にクラウドに送られることはありません。

### 使い方
1. **「ウィンドウ」→「検索パネル」** を開く（虫めがねアイコン）。
2. 検索欄に探したい内容を日本語で入力（例：「笑っている人のアップ」）。
3. 候補のクリップがサムネイルで並ぶので、ダブルクリックで確認してタイムラインへ。

### コツ
- 撮影日やカメラなどメタデータでの絞り込みも同じ検索欄からできます（例:「先週撮影した屋外のカット」）。
- 素材が多いほど威力を発揮します。Vlog などで「撮りっぱなし素材の山」から探すときに最適です。

## 11. オブジェクトマスク（人や物を AI が自動で切り抜き・追跡）

映像の中の**人物や物を AI が認識して自動で選択（マスク）し、動きに合わせて追跡**します。「人物だけ明るくする」「背景だけぼかす」「動く被写体の後ろにテロップを回り込ませる」といった、以前は上級者向けだった表現が数クリックでできます。

### 使い方（例：人物だけ明るく）
1. クリップを選択し、Lumetri カラーなど適用したいエフェクトを追加。
2. エフェクトコントロール（またはプログラムモニター）で **オブジェクトマスク** を作成し、対象の人物をクリックして選択。
3. AI がフレームをまたいで自動追跡します。追跡が外れたフレームだけ手動で修正。
4. マスクの内側（または反転して外側）にだけ効果がかかります。

> 💡 バージョン 26（2026年リリース）で搭載された比較的新しい機能です。メニュー位置の詳細は [公式ヘルプ](https://helpx.adobe.com/jp/premiere-pro/using/whats-new.html) を参照してください。

## 12. その他の便利 AI 機能

| 機能 | 何ができる | 場所・使い方 |
|---|---|---|
| **モーフカット** | インタビューのジャンプカット（カットした跡）を滑らかに補間 | エフェクト → ビデオトランジション → ディゾルブ → モーフカット をカット点にドラッグ |
| **シーン編集の検出** | 1本につながった動画からカット点を自動検出して分割 | クリップを右クリック → 「シーン編集の検出」 |
| **カラーマッチ** | 別のカットの色味に自動で合わせる | Lumetri カラー → カラーホイールとカラーマッチ → 「比較表示」→「一致を適用」 |
| **自動カラー補正** | 明るさ・色を AI がワンクリック補正 | Lumetri カラー → 基本補正 → 「自動」 |
| **自動トーンマッピング** | iPhone の HDR 素材などの白飛び・色ズレを自動補正 | シーケンス設定で「自動トーンマッピング」をオン |

## この章のまとめ：AI におまかせ編集の黄金パターン

しゃべり系 YouTube 動画なら、この順番が最短です。

1. 読み込み時に**自動文字起こし** ①
2. **テキストベース編集**で不要な発言・間をカット ③
3. **スピーチを強調**で声をクリアに ⑤
4. BGM を置いて**リミックス**で長さ調整 ⑥ → **オートダッキング** ⑦
5. **キャプション自動生成**＋トラックスタイルで字幕完成 ②（必要なら**翻訳** ④）
6. 文字起こし .txt を書き出して **Claude / Gemini でタイトル・概要欄を生成**（→ [04章](04_claude.md)・[05章](05_gemini.md)）
7. ショートも作るなら**オートリフレーム** ⑧

👉 実際に1本作る通しの手順は [06. 実践レシピ](06_workflows.md) へ。
