# 08. FAQ・用語集

## FAQ（つまずきやすいポイント）

### Q1. 文字起こしの精度が悪いです
- マイクと口の距離を近くして撮り直すのが根本対策です（ピンマイクや USB マイクの導入は費用対効果が高い投資です）。
- 撮ってしまった素材は、先に「**スピーチを強調**」を適用 → クリップを書き出してから文字起こしすると改善することがあります。
- 固有名詞の誤変換は文字起こしパネル上で直接修正できます。よく使う単語は都度直すより、Claude に .srt ごと校正してもらうのが速いです（→ [07章の8「字幕の校正」](07_prompts.md#8-字幕srtの校正)）。

### Q2. Premiere Pro の動作が重い・カクつく
- プログラムモニターの再生解像度を「1/2」「1/4」に下げる。
- 使っていないパネル（Lumetri スコープ等）を閉じる。
- 環境設定 → メディア → 「メディアキャッシュ」を定期的に削除。
- 4K 素材が重い場合は「プロキシ」（軽い代理ファイル）を作成して編集し、書き出し時だけ元データを使う方法があります（プロジェクトパネルで素材右クリック → プロキシ → プロキシを作成）。

### Q3. 生成拡張や Firefly の「生成クレジット」が足りません
- 生成クレジットはプランごとに毎月付与されます。残量は [Adobe アカウント](https://account.adobe.com/) で確認できます。
- 消費の激しい機能（動画生成）は月初に計画的に。上位プランや Firefly 単体プランの追加で増やせます。

### Q4. AI が作った台本・タイトルをそのまま使っていい？
- 権利的には利用可能ですが、**内容の正確性の責任は投稿者**にあります。事実確認は必須です。
- また、AI 特有の誇張・断定表現（「衝撃の」「99%が知らない」等）はチャンネルの信頼を削ることがあります。最後は自分の言葉に直しましょう。

### Q5. YouTube に「AI を使った」と申告する必要はある？
- YouTube には**リアルに見える改変・合成コンテンツの開示義務**があります（実在しない出来事を本物のように見せる映像、実在人物の顔・声の合成など）。該当する場合、アップロード時に「変更されたコンテンツ」の項目で開示します。
- 台本作成・字幕・タイトル生成・BGM 選定などの**制作補助としての AI 利用は開示対象ではありません**。
- AI ナレーションや Veo 生成のイメージ映像は、視聴者の誤解を招かない使い方なら義務ではないケースが多いですが、**概要欄に一言書いておくのが誠実でおすすめ**です。最新のルールは [YouTube ヘルプ](https://support.google.com/youtube/answer/14328491) を確認してください。

### Q6. Adobe Stock の素材で収益化して大丈夫？
- 標準ライセンスで基本的に OK とされていますが、エディトリアル素材は不可、50万回複製の上限条項があるなど条件があります。詳しくは [03章](03_adobe-stock.md#4-ライセンスの基本ここだけは読んでください) を参照。

### Q7. Gemini API でエラー `429` が出ます
- 無料枠のレート制限（1分あたり・1日あたりの回数）に達しています。少し待ってから再実行するか、有料の従量課金を有効にします（→ [05章](05_gemini.md#無料枠と有料の違い)）。

### Q8. API キーを間違えて公開してしまったかも
- すぐに [Google AI Studio](https://aistudio.google.com) で該当キーを**削除**し、新しいキーを発行してください。GitHub に push してしまった場合は、履歴からも消えたかに関わらず**必ず無効化**が先です。

### Q9. Claude と Gemini、結局どっちを使えばいい？
- 迷ったら：**文章を書く仕事は Claude、動画・音声を扱う仕事と自動化は Gemini**。両方に同じ依頼をして良い方を採る二刀流も普通にアリです（→ [05章の分担表](05_gemini.md#6-claude-と-gemini-の分担まとめ)）。

### Q10. 書き出した動画の画質が悪い
- 書き出しプリセットが低解像度になっていないか確認（YouTube 1080p 推奨）。
- ビットレート設定（VBR, 1パス、ターゲット 16Mbps 前後が 1080p の目安）。
- そもそも素材が暗い・ノイズが多い場合は撮影側の改善（明るさ）が効きます。

### Q11. 編集データはどうバックアップすべき？
- プロジェクトファイル（.prproj）と素材フォルダーを丸ごと外付けドライブ等にコピーが基本。
- Premiere の自動保存フォルダー（プロジェクトと同じ場所の `Adobe Premiere Pro Auto-Save`）も知っておくと事故時に助かります。

### Q12. ここに書いてある画面と実物が違います
- Premiere Pro・各 AI サービスはアップデートが頻繁です。機能名で検索するか、各章に貼った公式リンクで最新の手順を確認してください。このマニュアルは 2026年7月時点の情報です。

## 用語集

### 編集の基本用語

| 用語 | 意味 |
|---|---|
| プロジェクト | 動画1本分の作業ファイル。素材への「リンク」を持つだけで、素材そのものは含まない |
| シーケンス | クリップを時間軸に並べたもの。1プロジェクトに複数作れる（本編用・ショート用など） |
| クリップ | タイムラインに置かれた個々の動画・音声・画像 |
| タイムライン | シーケンスを編集する画面。V1, V2…が映像トラック、A1, A2…が音声トラック |
| カット / トリミング | 不要部分を切ること。クリップの端をつまんで縮めるのがトリミング |
| リップル削除 | 削除してできた隙間を自動で詰める削除 |
| Bロール | メインのしゃべり（Aロール）に重ねる補足映像・イメージカット |
| テロップ | 画面に表示する文字の総称 |
| キャプション | しゃべりに同期した字幕。専用トラックで管理される |
| トランジション | カットの切り替え効果（ディゾルブなど） |
| キーフレーム | 「この時点でこの値」という点。音量や位置を時間変化させる仕組み |
| レンダリング | 編集内容を計算して滑らかに再生できるようにする処理 |
| 書き出し（エクスポート） | 完成動画を1本のファイルにすること |
| プロキシ | 重い素材の代わりに使う軽量コピー。編集を軽くする |

### 映像・音声の用語

| 用語 | 意味 |
|---|---|
| 解像度 | 映像の細かさ。1920×1080（フルHD）が YouTube の標準 |
| アスペクト比 | 画面の縦横比。横動画は 16:9、ショートは 9:16 |
| フレームレート（fps） | 1秒あたりのコマ数。30fps が標準、滑らかさ重視なら 60fps |
| H.264 / MP4 | YouTube 向けの定番の圧縮形式／ファイル形式 |
| ビットレート | 1秒あたりのデータ量。高いほど高画質・大容量 |
| dB（デシベル） | 音量の単位。0dB を超えると音割れ。しゃべりは -6dB 前後が目安 |
| ゲイン / ラウドネス | 音量の増幅／人間の聴感上の音の大きさ |
| ホワイトバランス | 映像の色の偏り（青っぽい・黄色っぽい）の補正 |
| LUT | 色味のプリセット。映画風などの見た目を一発適用 |

### AI・サービス関連の用語

| 用語 | 意味 |
|---|---|
| Adobe Sensei / Firefly | Adobe の AI 技術の名前。Sensei は解析系、Firefly は生成系 |
| 生成クレジット | Adobe の生成 AI 機能（Firefly、生成拡張など）の利用枠。毎月付与 |
| コンテンツクレデンシャル | 「AI 生成である」等の来歴情報をファイルに埋め込む仕組み |
| プロンプト | AI への指示文 |
| トークン | AI が文章を数える単位。API の課金・制限の基準 |
| API / API キー | プログラムからサービスを呼び出す窓口／その認証鍵 |
| レート制限 | 一定時間あたりの API 利用回数の上限 |
| TTS（Text-to-Speech） | テキスト読み上げ＝音声合成 |
| SRT | 字幕ファイルの標準形式。番号＋タイムコード＋テキストの繰り返し |
| LLM | 大規模言語モデル。Claude や Gemini の中身 |
| ハルシネーション | AI がもっともらしい嘘を言う現象。事実確認が必要な理由 |
| SynthID | Google の生成コンテンツに入る電子透かし |

### YouTube 運用の用語

| 用語 | 意味 |
|---|---|
| サムネイル | 一覧に表示される表紙画像。クリック率を左右する最重要素材 |
| インプレッション / CTR | 表示された回数／そのうちクリックされた率 |
| 視聴維持率 | 動画のどこまで見られたかの割合。アナリティクスで折れ線表示 |
| チャプター | 概要欄のタイムコードで動画を章分けする機能 |
| 概要欄（説明欄） | 動画の下の説明文。検索にも影響 |
| タグ | 動画に付ける検索用キーワード（現在は影響小さめ） |
| 終了画面 / カード | 動画の最後・途中に出す誘導パーツ |
| ショート | 60秒〜3分以内の縦型動画 |
| 限定公開 | URL を知っている人だけ見られる公開設定。確認用に便利 |
