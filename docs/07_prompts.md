# 07. プロンプト集 〜コピペで使える AI への頼み方〜

Claude（claude.ai）と Gemini（gemini.google.com）のどちらでも使える文例集です。
**【 】の部分を自分の内容に書き換えて**使ってください。

> 💡 使い方のコツ
> - 1回で完璧を求めず、出力に対して「もっと◯◯に」と会話で追い込む。
> - チャンネルの前提（ジャンル・視聴者・トーン）は毎回書くか、Claude のプロジェクト機能に登録しておく（→ [04章](04_claude.md#3-プロジェクト機能でチャンネル情報を記憶させる)）。
> - 事実（数値・日付・仕様）は必ず自分で確認する。

---

## 企画・構成

### 1. 企画・ネタ出し

```
私は【ジャンル：例 自炊初心者向けの料理】の YouTube チャンネルを運営しています。
視聴者は【例：一人暮らしを始めたばかりの20代】です。

このチャンネルで作る動画の企画を10本提案してください。
それぞれ以下の形式で：
- 仮タイトル
- 内容の要約（2行）
- 視聴者がクリックしたくなる理由
- 制作の手間（低・中・高）

条件：
- 【例：特別な機材や食材を使わない】
- 【例：季節ネタを2本以上含める】
```

### 2. 構成案

```
次のテーマで【10】分の YouTube 動画を作ります。
テーマ：【例：初心者がやりがちな包丁の使い方の間違い5選】

視聴者が最後まで見たくなる構成案を作ってください。
- 冒頭15秒の「つかみ」の案を3パターン
- セクションごとの見出しと目安時間
- 途中離脱されやすいポイントとその対策
- 最後の「まとめ＋次の動画への誘導」の流れ
```

## 台本

### 3. 台本執筆

```
以下の構成案をもとに、YouTube 動画の台本を書いてください。

構成案：
【ここに 2.（構成案）の出力を貼る】

条件：
- 話し言葉。一人称は【私／僕】、口調は【例：友達に話すようなカジュアル】
- 1文を短く、聞いてわかる言葉で（漢語より和語）
- 画面に出す資料・テロップの指示は［テロップ：〜］の形で行間に入れる
- 全体で読み上げ【8】分程度（1分あたり約300字が目安）
```

### 4. 台本の調整（よく使う修正指示）

```
・全体を30秒ぶん短くして。削る優先度が低いのは【◯◯の説明】です
・冒頭のつかみを、疑問形で始まるパターンに変えて
・【専門用語】を小学生でもわかる例え話に置き換えて
・ナレーション向けに、目で読む文章ではなく耳で聞いてわかる文章に直して
```

## 公開準備（メタデータ）

### 5. タイトル・概要欄・タグの一括生成

Premiere Pro から書き出した文字起こし .txt（→ [02章](02_premiere-ai-features.md#1-自動文字起こしすべての土台)）を添付して：

```
添付は私の YouTube 動画の文字起こしです。この内容をもとに以下を作ってください。

1. タイトル案を5つ（60文字以内／煽りすぎない／検索されそうな言葉を入れる）
2. 概要欄（最初の2行で内容がわかるように。全体で400字程度。
   ハッシュタグを3つ末尾に）
3. タグを15個（カンマ区切り）
4. チャプター案（00:00 形式。文字起こしのタイムコードを参考に5〜8個）

チャンネルの前提：【ジャンル／視聴者／トーン】
```

> 💡 同じことを自動化するスクリプト：[scripts/gemini/generate_youtube_metadata.py](../scripts/gemini/README.md)

### 6. チャプターだけ欲しいとき

```
添付の文字起こし（タイムコード付き）から、YouTube のチャプターを作ってください。
- 00:00 から始める
- 5〜8個、各チャプター名は15文字以内
- 「00:00 チャプター名」の形式で、そのまま概要欄に貼れる形で出力
```

### 7. サムネイル文言

```
この動画のサムネイルに載せる文言を考えてください。
動画の内容：【1〜2行で要約 or 文字起こしを添付】

条件：
- 13文字以内の案を10個
- 「数字入り」「疑問形」「危機感」「ベネフィット」の型をまぜる
- あわせて、文字を目立たせる配色（背景色×文字色）の提案も3つ
```

## 字幕・翻訳

### 8. 字幕（.srt）の校正

.srt ファイルを添付、または内容を貼り付けて：

```
これは YouTube 動画の字幕ファイルです。以下のルールで校正してください。

- 番号とタイムコードは絶対に変更しない
- 誤字脱字、文字起こしの誤変換（同音異義語）を修正
- 「えー」「あの」などのフィラーは削除
- 1行が長すぎる場合は読みやすい位置で改行
- 修正後の .srt をそのままコードブロックで出力
- 最後に、修正した箇所の一覧を表で
```

### 9. 字幕の翻訳（少量ならチャットで）

```
この .srt を自然な英語に翻訳してください。
- 番号とタイムコードは変更しない
- 直訳ではなく、YouTube の字幕として自然な口語に
- 日本語特有の表現は意訳し、必要なら短くする（読み切れる長さ優先）
```

> 💡 本数が多い・定期的にやるなら自動化：[scripts/gemini/translate_srt.py](../scripts/gemini/README.md)

## 素材集め

### 10. Adobe Stock 検索キーワード

```
以下の台本の【セクション名】部分に挿入する映像素材を Adobe Stock で探します。
ヒットしやすい英語の検索キーワードを10個、
「キーワード / 想定している画のイメージ」の表で提案してください。

台本：
【該当部分を貼る】
```

### 11. 画像・動画生成用プロンプト（Firefly / Veo 用）

```
【シーンの説明：例 朝日が差し込むキッチンで湯気の立つ味噌汁】の映像を
生成 AI で作ります。Firefly（または Veo）に入力する英語プロンプトを、
構図・ライティング・カメラの動き・雰囲気の指定込みで3パターン書いてください。
縦横比は【16:9】です。
```

## ショート・運用

### 12. ショートの切り出し選定（Gemini 向け）

動画ファイルまたは YouTube URL を渡して：

```
この動画からショート動画（60秒以内）に切り出すのに最適な箇所を3つ提案してください。
それぞれ：
- 開始〜終了のタイムコード
- そこを選んだ理由（フックの強さ）
- ショート冒頭に載せる1行フックのテロップ案
```

### 13. ショートのフック・タイトル

```
このショート動画の冒頭0〜2秒に表示するフック（1行テロップ）と、
ショートのタイトルを考えてください。
内容：【要約 or 台本を貼る】
- フック案を10個（15文字以内、スクロールの指を止めることが目的）
- タイトル案を5個
```

### 14. コメント返信案

```
私の動画に次のコメントが来ました。返信案を3パターン（丁寧め／フランク／短め）
書いてください。チャンネルのトーンは【例：親しみやすく、絵文字は控えめ】です。

コメント：
【貼り付け】
```

### 15. アナリティクス相談

YouTube Studio の視聴維持率グラフのスクリーンショットを添付して：

```
これは【動画タイトル】の視聴維持率グラフです。動画の構成は以下の通りです。
【チャプターやタイムコード付きの構成を貼る】

- 大きく離脱しているタイミングと、考えられる原因を分析してください
- 次回の動画で試すべき改善策を、優先度順に3つ提案してください
```
